# Day 16 - Conditional Styles in React

## Scenario

How to apply styles dynamically in React based on conditions or state?

## Solution

Implemented conditional styling using both inline styles and conditional className to dynamically update UI based on state changes.

## Implementation

* Used inline styles for dynamic style changes
* Applied conditional className based on state
* Updated styles using ternary operators
* Controlled UI appearance based on user interaction

## Key Learning

Conditional styling helps create dynamic and interactive user interfaces by applying styles based on state or conditions in React.

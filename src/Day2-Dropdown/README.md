# Day 2 - Dropdown in React

## Scenario
How to implement a dropdown (select menu) in React and manage user selection?

## Solution
Built a dropdown component to allow users to select options dynamically using React state.

## Implementation
- Used useState to manage selected value  
- Rendered dropdown options dynamically  
- Handled onChange event to update selected option  
- Displayed selected value in UI  

## Key Learning
Dropdowns help in handling user input efficiently and improve UI interaction by providing controlled selection options.

# Day 7 - Conditional Dropdown

## Scenario
How to create dependent dropdowns where the options in one dropdown change based on the selection of another?

## Solution
Built a **conditional dropdown** where selecting a country dynamically updates the list of states using React state.

## Implementation
- Used **useState** to manage selected country and states  
- Created a data structure for countries and their respective states  
- Updated state list dynamically based on selected country  
- Rendered dropdown options conditionally  

## Key Learning
- How to handle dependent dropdowns in React  
- Managing dynamic data using state  
- Conditional rendering based on user selection  
- Improving user experience with interactive forms

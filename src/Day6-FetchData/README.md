# Day 6 - Data Fetching using Axios

## Scenario
How to fetch and display data from an API in a React application?

## Solution
Used **Axios** to make API requests and fetch data, then displayed it in the UI using React state.

## Implementation
- Installed and used **Axios** for API calls  
- Used **useEffect** to fetch data on component mount  
- Stored API response using **useState**  
- Handled loading and error states  
- Rendered fetched data dynamically  

## Key Learning
- Axios simplifies API calls compared to fetch  
- useEffect helps run side effects like data fetching  
- Managing loading and error states improves user experience  
- Data can be dynamically rendered using React state

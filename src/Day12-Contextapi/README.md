# Day 12 - Context API in React

## Scenario

How to avoid prop drilling and share data across multiple components in React?

## Solution

Implemented Context API to manage global state and pass data without manually passing props through each component.

## Implementation

* Created context using createContext
* Wrapped components with Context Provider
* Used useContext to access shared data
* Managed global state efficiently

## Key Learning

Context API helps in simplifying state management and improves code structure by avoiding unnecessary prop passing between components.

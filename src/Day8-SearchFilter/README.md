# Day 8 - Search Filter

## Scenario
How to filter and display data dynamically based on user input in a React application?

## Solution
Implemented a **search filter** that updates the displayed list in real time as the user types.

## Implementation
- Used **useState** to manage input value  
- Stored list data in state  
- Filtered data using `filter()` method  
- Updated UI dynamically based on search input  

## Key Learning
- Filtering data dynamically using JavaScript  
- Managing user input with useState  
- Real-time UI updates based on search input  
- Improving user experience with interactive search

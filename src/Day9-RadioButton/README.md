# Day 9 - Radio Button

## Scenario
How to handle single selection input in a React application using radio buttons?

## Solution
Implemented **radio buttons** to allow users to select one option from multiple choices and manage the selected value using React state.

## Implementation
- Used **useState** to store selected value  
- Handled change events using `onChange`  
- Ensured only one option is selected at a time  
- Displayed selected value dynamically  

## Key Learning
- Managing single selection inputs in React  
- Handling form inputs using state  
- Controlled components for better control over UI  
- Real-time updates based on user selection

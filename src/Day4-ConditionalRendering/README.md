# Day 4 - Conditional Rendering in React

## Scenario
How to render UI elements conditionally based on user actions or state?

## Solution
Implemented conditional rendering using **ternary operator** and **logical AND (&&) operator** in React.

## Implementation
- Used **ternary operator** for rendering elements based on conditions  
- Used **&& operator** to display elements when a condition is true  
- Managed conditions using useState  
- Dynamically updated UI based on user interaction  

## Key Learning
Conditional rendering helps in building dynamic and interactive UIs by displaying content based on specific conditions.

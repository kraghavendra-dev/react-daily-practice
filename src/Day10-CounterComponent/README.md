# Day 10 - Counter Component

## Scenario
How to manage and update state dynamically in a React application based on user interactions?

## Solution
Built a simple counter application using **useState hook** to handle state changes and update the UI in real time.

## Implementation
- Used **useState** to manage counter value  
- Created buttons for increment, decrement, and reset  
- Handled click events to update state  
- Rendered updated value instantly on UI  

## Key Learning
Understanding how state works in React and how UI re-renders automatically when state changes. This is a fundamental concept for building interactive applications.

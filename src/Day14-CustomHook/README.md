# Day 14 - Custom Hook in React

## Scenario

How to reuse logic across multiple components in React without duplicating code?

## Solution

Created a custom hook to extract and reuse common logic, making components cleaner and more maintainable.

## Implementation

* Created a custom hook function using "use" naming convention
* Used useState and useEffect inside the hook
* Returned reusable logic from the hook
* Consumed the custom hook in multiple components

## Key Learning

Custom hooks help in reusing logic, improving code readability, and making React applications more scalable and maintainable.
